# 图片描述规范

> 你只负责写**描述文字**，出图由系统自己的模型完成。
> 写的是"这张图里有什么"，不是"怎么拍"。

## 一、人物立绘描述（`savePeopleDesc`）

系统会在这段描述前面自动拼上书籍的画风（`peopleStyle`），末尾固定加「去除背景」。
所以：

- **不要写画风**（不要写"3D 动画风""水墨风""写实"），会和书籍画风打架。
- **不要写背景/环境**（立绘要抠图，写背景只会让背景糊在身上）。
- **不要写镜头/构图**（不要写"半身像""特写""正面站立"，系统自己控制）。

要写的：

1. **性别 + 年龄段**（和人物表里的 `six` / `ageType` 一致，不要矛盾）。
2. **外貌**：脸型、五官特征、肤色、有无疤痕/痣/胡须。
3. **发型发色**（要具体：高马尾、齐耳短发、银白长发）。
4. **服饰**：上衣、下装、外袍/披风、配饰、鞋（要能区分出这个角色的身份气质）。
5. **体型**：高矮胖瘦、肩宽、体态。
6. **气质/表情基调**：冷峻、温润、阴鸷、俏皮。

模板：

```
<年龄><性别>，<脸型与五官>，<发型发色>，<上衣与下装细节>，<配饰>，<体型>，<气质基调>
```

例子：

```
青年男性，面部轮廓硬朗、眉骨突出、眼神锐利，黑色短发微乱，身着深灰色劲装、外罩玄色短披风，腰间挂一枚铜色令牌，身形挺拔偏瘦，气质冷峻
```

长度建议 60~120 字。**同一角色换镜不要改这段描述**，否则会串脸。

## 二、场景描述（`saveAssetDesc`，type=场景）

系统会把描述拼上画风，并加「无人物的场景空镜、只出现描述中的景物、无文字无水印」，且强制横屏。

所以：

- **绝对不要写人物**（写了会生成人，场景图就废了）。
- **不要写镜头运动**（"镜头推进""环绕"是分镜的事）。
- **不要写时间轴上发生的事**（"然后天黑了"），只写一个静态瞬间。

要写的：

1. **地点类型**（客栈大堂、宗门山门、王府花园、地下墓室）。
2. **建筑与地貌特征**（结构、材质、新旧、损毁程度）。
3. **光线与时间**（晨光斜照、昏黄灯笼、阴云密布、月下冷光）。
4. **氛围**（肃杀、温暖、荒凉、压抑）。
5. **关键陈设 2~5 件**（牌匾、香炉、屏风、石阶、枯树）。

例子：

```
破败的古镇街口，两侧木质店铺门板斑驳脱落，青石板路面积水反光，檐下挂着褪色灯笼，远处一座石拱桥隐在薄雾中，阴天傍晚，光线冷灰，气氛荒凉萧索
```

## 三、道具描述（`saveAssetDesc`，type=道具）

系统会加「单个道具主体、居中构图、干净纯色背景、无人物无文字」。

要写的：

1. **是什么**（玉佩、长剑、符纸、药瓶）。
2. **形制与形状**（长条形、圆形、带缺口）。
3. **材质**（青铜、白玉、粗布、朽木）。
4. **颜色与纹理**（暗红、有裂纹、缠着金丝）。
5. **尺寸感**（巴掌大、半人高）。

例子：

```
一枚圆形白玉玉佩，玉质温润微透，边缘刻细密云纹，正中央有一个指节大小的缺口，系着褪色的暗红色丝绳，巴掌大小
```

## 四、通用红线

- 描述里**不要出现"应该""可以""建议"这类指令语气**，只做客观描述。
- 描述里不要有换行，写成一段。
- 一个素材一个主体。要两个物体就分两个素材。
- 已经 `hasPicture=true` 的，除非用户明确要求重画，否则不要改描述、不要重新出图（重出会覆盖，之前的图就丢了）。
