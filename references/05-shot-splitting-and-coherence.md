# 分镜切分 与 参考上一镜

两件事决定成片"顺不顺"：

1. **切在哪** —— 一个镜头该多长、什么时候必须换行
2. **要不要接上一镜** —— 这一镜该不该拿上一镜的尾帧当参考

---

## 一、什么时候必须拆成新的一行（换镜头）

**必拆的五种情况**：

| 情况 | 为什么 | 例子 |
|---|---|---|
| **换人说话** | 一行只能有一个说话人，多个人说话必须一人一行 | 张三说完李四接话 → 拆 |
| **人物不在同一画面** | 相机只能拍眼前的东西 | 「楼上的张三看着楼下的李四」→ 拆成两行，第二行用运镜转下去 |
| **换地点** | 不写地点模型会停在上一个场景 | 从屋里到街上 → 新行先写「闹市街头，人流穿梭…」 |
| **时间跳跃** | 「三天后」「当晚」 | 新行先写时间与场景变化 |
| **单镜超过上限** | 超过 `maxDurationPerScene`（默认 10~12s）会被硬切 | 台词多就拆成两行，前一行写画面、后一行写台词 |

**不用拆的情况**（拆多了反而碎）：

- 一个人连贯说一整段话 → 一行
- 一个人的连续动作（站起来、走过去、推门）→ 一行，用逗号串起来
- 同一画面里的环境细节 → 并进当前行

**判断口诀**：**换人说话、换地方、换时间、镜头看不见 → 拆；其它都别拆。**

## 二、一行写多长

- 有台词的行：**台词汉字数 ÷ 语速**（`getBookContext` 的 `hanziPerSecond`，一般 4 字/秒）
  - 8 个字 → 2s；20 个字 → 5s
  - 台词长就如实写长，**不许靠删台词、并句来省时间**
- 没台词的行：1~3 秒。**动作多、运镜复杂才给 3 秒**，否则 1~2 秒
- 一行的描述文字控制在 **60~120 字**，太长了模型抓不住重点

## 三、要不要「参考上一镜」

数据库字段 `XS_SCENE.COHERENT`：`1` = 拿上一镜的最后一帧当参考（保证人物、光线、场景连续），`0` = 不参考。

**要参考（填 1）**：

- 同一场景、同一批人物，**动作在延续**（追、打、走、拥抱、递东西）
- 上一个镜头人物在画面里，这个镜头还是他们，只是景别变了（中景 → 特写）
- 对话正反打（A 说话 → B 反应 → A 再说话），人物位置不能跳

**不要参考（填 0）**：

- **换场景**（地点变了）
- **时间跳跃**（「三天后」「第二天早上」）
- **空镜 / 物件特写**（产品特写、风景、道具）—— 参考了反而把上一镜的人物糊进来
- **转场镜**（黑场、淡出、闪回）
- **第一镜**（没有上一镜）
- 上一镜是纯空镜、这一镜才出现人物

**判断口诀**：**人和景都接着上一镜 → 要参考；只要有一项变了 → 不参考。**

## 四、怎么设置

逐镜判断完，**一次批量写**（不要一镜一个请求）：

```
POST {地址}/api/agent/scene/coherent
表单：sceneIds=3,4,5  coherent=1
```

先设所有该参考的为 1，剩下的保持默认 0。

## 五、举个完整例子

一段戏：王蝉在院中与燕如嫣对话，然后转身走出院门，镜头切到街市。

| 镜 | 内容 | 拆的理由 | 参考上一镜 |
|---|---|---|---|
| 1 | 中景，王蝉站在院中，【王蝉】说道：“你走吧。” | 开场 | **0**（第一镜） |
| 2 | 近景，燕如嫣低头，双唇紧闭，眼眶泛红 | 换人、景别变化 | **1**（同场景同人物） |
| 3 | 中景，王蝉转身走向院门，背影消失在门洞 | 同场景，动作延续 | **1** |
| 4 | 全景，闹市街头，人流穿梭，两侧摊贩叫卖 | 换地点 | **0** |
| 5 | 特写，一块铜色令牌落在青石板上 | 空镜物件 | **0** |

批量设置：`sceneIds=2,3  coherent=1`，其余不动。

**注意第 5 镜**：如果给它填 1，模型会把第 4 镜街道里的人糊到令牌上，物件特写就废了。
