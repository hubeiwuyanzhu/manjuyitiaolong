# 成片验收标准

> 验收分两段：**机器判硬指标**（`checkSceneVideo`）+ **你看帧判主观项**（`extractFrames`）。
> 两段都过才算通过。有一项不过就判不合格，必须改提示词重跑。

## 一、机器硬指标（`checkSceneVideo`，`pass` 字段）

| 项 | 判定 | 不通过的后果 |
|---|---|---|
| 时长 | 实际与预期偏差 ≤ 0.5s | 被硬切 / 被静音补齐，画面会断 |
| 音轨 | `hasAudio=true` | **台词全丢**，等于废片，必须重跑 |
| 音画一致 | 音频时长与视频时长差 ≤ 1s | 台词错位、尾部留白 |
| 分辨率 | 与书配置差 ≤ 8px | 合并时黑边或拉伸 |
| 黑帧 | 黑帧总时长 ≤ 0.5s | 塌片、编码失败 |

`issues` 里任何一条都算不合格。注意：**"没有音轨"是最常见也最致命的**，见到就直接重跑，别再看帧了。

## 二、你看帧判的主观项（`extractFrames`）

### 抽帧姿势

1. 先 `extractFrames(sceneId, fps=1)` 抽整片（1 秒 1 张，一次最多 24 张）。
2. 超过 24 张的片子分段看：`from=0,to=8` → `from=9,to=16` → …
3. 发现可疑秒数，再单独抽那一小段（如 `from=4,to=6`）确认。
4. **一定要真的看图**，不要凭提示词推测画面。

### 逐项判

**① 画面与提示词是否一致**
- 提示词写的地点、人物、动作、道具，画面里有没有？
- 有没有出现提示词里根本没写的人或物（多余的人最容易出）。
- 换场景的那一镜，场景有没有真的换过来（没换 = 停在上一景，典型白底/同背景）。

**② 人物一致性**
- 同一角色在不同镜之间，脸、发型、服装是否一致。
- 有没有串脸（A 镜的脸长到 B 身上）、多手多指、糊脸、面部扭曲。
- 有没有"人物粘连"（两个人黏成一团）——高分辨率塌片的典型症状。

**③ 口型与台词**

> 模型**没有对口型能力（无 lip-sync）** —— 嘴型与台词对不上（该说话的秒数嘴没动、动了但节奏对不上）都是**预期行为，不算不合格**，别为这个重跑。

- 仍然判不合格的是**音频层**问题：没有台词的段落出现了人声（模型自己编的乱音）→ 不合格。
- **多人同框 + 非说话人张嘴乱说话 → 不改提示词，直接停手交人**（见第三节特例）。
- 说话人自己没台词的时段张嘴，仍按下面的重跑流程改提示词。

**④ 字幕与水印**
- 画面里出现任何文字、字幕条、水印、logo → 判不合格。
- 唯一例外：提示词里明确要求出现的画面文字（门匾、招牌、纸条）。这种要和用户确认是否接受。

**⑤ 连贯性**
- 相邻两帧之间有没有跳变、闪黑、画面撕裂。
- 镜头内运动是否自然（人物突然瞬移、衣服突变 → 不合格）。
- 和上一镜的衔接：这一镜开头有没有接上上一镜结尾的位置和朝向。

## 三、判定与重跑

### 结论只允许两种

- **通过** → 调 `retry/reset(sceneId)` 清零，汇报"第 N 镜通过（时长 X.Xs，抽帧 Y 张）"。
- **不通过** → 必须能说出**具体秒数 + 具体问题**，例如：
  - `6s 处没有人说话，但画面里出现了说话口型，还混进了乱音`
  - `7s 起画面底部出现白色字幕条`
  - `整片背景是纯白，场景图没被引用`
  - `第 2、3 帧之间人物位置跳变`

说不清具体问题 = 你还没真看，回去重抽。

### 重跑流程（顺序不能乱）

1. `getRetryStatus(sceneId)` 看已重跑几次（不要凭记忆）。
2. **先判断不合格原因是不是「多人同框 + 非说话人乱开口」**（下条特例单独讲）。是 → 不许重跑，直接停手交人。
3. **按不合格的具体原因改分镜提示词**。对应关系：
   - **说话人自己**没台词却张嘴 → 那一行加「双唇紧闭，无说话口型，只做表情反应」
   - 口型与台词不同步 → **不是不合格项**（模型无 lip-sync），别为这个重跑
   - 画面白底/丢场景 → 第一行补上地点与景物描述
   - 人物串脸 → 第一行补人物外观锚点（发型、服饰、体态），避免与另一角色相似
   - 有字幕 → 每行末尾加「无字幕、无文字、无水印」（模型仍可能烧字幕，治不了就交人）
   - 情节跳变 → 拆行，或用运镜句衔接（「镜头由窗户转向街道」）
   - 时长偏差大 → 调整各行行首用时（偏差大通常是某行用时与台词量不匹配）
3. `validateScenePrompt` 通过 → `saveScenePrompt` 保存。
4. `reportRetry(sceneId, note, checkResult)`：
   - `allow=false` + "提示词与上次完全相同" → 你其实没改，回去改。
   - `allow=false` + "达到上限" → 停手，把问题和所有不合格帧交给用户。
   - `allow=true` → 回出片阶段重跑。
5. **最多 3 次**。第 3 次仍不合格必须停手，不许继续。

### 🔴 特例：多人同框、非说话人乱开口 → 不许重跑，直接停手

**症状**：两人（或多人）正脸同框，一人说话，**另一个人也在张嘴**（甚至也出了声）。

**提示词路线已实证无效**（2026-11-12 试了 12 版：中文点名「XXX 全程嘴唇紧闭」、英文行为约束、尾帧作用域收窄，全部无效）。
根因是模型的音频条件是**整轨的、绑不到具体某张脸** —— 音频会驱动画面里所有正脸的嘴，改提示词解决不了。
再按普通流程烧 3 次重跑（每镜 7~8 分钟）纯属浪费，**这是硬性停手条件**。

交人时给出三条出路（用户选）：
1. **改构图**：非说话人背身/侧脸/出画。注意「参考上一镜」会把上一镜构图钉死（见 `05-shot-splitting-and-coherence.md`），双人正脸同框的镜要先把 COHERENT 置 0。
2. **拆镜**：一镜只留一张正脸，靠衔接。
3. **接受现状**，或用户自己在软件里做后期修嘴。

### 停手时要给出什么

- 这一镜的 sceneId 和序号。
- 3 次分别改了什么（一句一版）。
- 每次的不合格项（机器 issues + 你的看帧结论）。
- 不合格帧的 URL。
- 给用户 2 个选项：改文案/改分镜结构，或降低要求接受这一版。
