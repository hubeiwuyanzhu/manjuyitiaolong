# 分镜提示词规范

> 这份规范决定画面会不会崩。系统里一段"分镜提示词"会被拼成视频模型的指令：
> **一行 = 一个镜头（shot）**，行首的用时决定这一镜在成片里占多长。

## 一、每行的写法

格式固定三段，按需出现：

```
<用时> <画面描述（必写）> 【<说话人>】<引导语>：“<台词>”。 <环境音（有才写）>
```

例子：

```
1s 王蝉戴着银色面具，面无表情，拉着燕如嫣的手，两人一步步走向法阵中心，银发老者在两人身后，脚步沉稳。
2s 中景，王天胜悬浮在半空，单手向前一挥，五颜六色的光柱从旗尖喷射而出，打在法阵节点上，【王天胜】平静地说道：“传送开始。”
3s 中景，霞光笼罩三人，三人在刺目光芒中瞬间消失，【王天胜】抬手示意，说道：“鬼灵门弟子，依次上前。”。环境音：山石倒塌的声音。
```

**行首用时（必须有，没有就废）**
- 写法只认 `2s` / `1.5s` 这种，不要写"2秒""两秒"。
- 有台词的行：用时 = 该行台词汉字数 ÷ 语速（`getBookContext` 返回的 `hanziPerSecond`，默认约 4 字/秒）。台词长就如实写长。
- 没有台词的行：按 1~3 秒写。
- **总时长由系统逐行相加，不要凑任何总数。**
- 只要有一行没写用时，整镜时长会退回人工填的值 —— 所以宁可多写，不能漏。

## 二、治「乱说话」（最高优先级）

**症状**：成片里明明没有台词的段落，人物自己开口说一段莫名其妙的话。

这是这套流程里最影响成片质量的问题，多半是提示词写错导致的。三个成因，逐条对着改：

**① 有 `【说话人】` 但台词没被引号包住**

```
错：2s 【张三】低声说道：你走吧
对：2s 【张三】低声说道：“你走吧”
```

没引号 → 系统判成"这行没有台词" → 音色绑不上；可画面里又写了说话动作 → 模型自己往下编。

**② 没有台词的行写了说话动作**

```
错：1s 王蝉站在门口，低声念了几句，转身离开
对：1s 王蝉站在门口，双唇紧闭，只有眼神闪动，转身离开
```

只要出现 `说话 / 低声 / 喃喃 / 自语 / 念叨 / 嘟囔 / 嘀咕 / 出声 / 张口 / 开口`
（且不是「双唇紧闭」「无说话口型」这类防口型描述），模型就会真的生成一段语音，内容不可控。

**③ 无台词的行给的时间太长**

留白太长，模型会在空白里"找事做"。把行首用时压到 1~2 秒，或拆成两个短 shot。

**判定口诀**：**有引号才算台词；没引号的行不许出现说话类动词。**

## 三、硬约束（系统会校验，不过不许写库）

1. **行首用时之和 ≤ `maxDurationPerScene`**（`getBookContext` 返回）。超了生成时会被硬切，画面断在中间。
2. **一行最多一个 `【说话人】`**，且这个人必须在该书的**人物名单**里、且 `hasVoice=true`。否则音色绑不上，台词进不了视频。
3. **台词必须逐字保留**：不能删、不能改字、不能拆成两句、不能合并两行、不能换人。画面写不下就加行，不能让台词让位。
4. **一行只能描述一个镜头**。相机只能拍眼前的东西，一行里出现"楼上的人 + 街上的事"就必须拆两行，用运镜衔接。

## 四、内容要求

- **第一行必须和上一镜最后一帧衔接**：写具体的人物位置、朝向、动作，**不要写"承接上镜""继续之前"**这种话。
- **禁止复述前面分镜的任何画面、动作、台词**。上一镜内容只用来判断从哪里接。
- **换场景必须先写地点**：从家里切到闹市，第一句就要写"闹市街头，人流穿梭，两侧摊贩……"，否则画面会停在上一个场景。
- **人物出场必须写清从哪里进来**："从画面左侧阴影中走出""推门而入，站在门槛处"。
- **抽象词改成画面**：「他很惊恐」→「他瞳孔收缩、嘴唇发抖、后退半步」；「好像看到了什么」→「他猛地抬头，眼睛直勾勾盯着前方」。
- **说话人标记 `【】` 只有这一个用途**：标这一行那句台词是谁说的，位置必须在台词之前（可以隔着引导语，如 `【张三】心中暗想（旁白）：“……”`）。
  - 画面描述里出现的其他人名**一律裸写**，加 `【】` 会把音色绑到错的人身上。
  - 没有台词的行不写 `【】`。
  - 一行最多一个 `【】`。
- **引号判断标准**：引号里是"人物说出来/心里想的"就保留引号；引号里是画面里可见的文字（招牌、门匾、纸条、屏幕）才去掉引号。
  - `人名：“台词”` 和 `【人名】：“台词”` 这两种写法必须原样保留，**不要改写成 `人名：台词`**（没引号会被判成"这行没台词"，音色绑不上）。

## 五、旁白 / 画外音 / 内心独白

- 说话人不张口也要标：`【张三】（旁白）：“他这一走，就是三年。”`
- 这类行**有台词**，必须保留 `【】` 和引号。画面描述里补一句"双唇紧闭，只有眼神变化"，防止模型硬做口型。

## 六、常见不合格原因（自查清单）

写完后自己过一遍：

- [ ] 每一行都有 `2s` 这种行首用时？
- [ ] 每行最多一个 `【】`，名字在人物名单里？
- [ ] 台词一个字没少、引号还在？
- [ ] 有没有一行写了两个镜头？
- [ ] 第一行有没有写"承接上镜"这种废话（要改成具体动作）？
- [ ] 有没有复述上一镜的画面/台词？
- [ ] 换场景的那一行有没有先写地点？
- [ ] 用时之和有没有超过本镜上限？
- [ ] **同一句台词有没有在同一镜里出现两遍？**
- [ ] **有没有把上一镜的台词又写了一遍？**（上一镜内容只用来判断衔接）

## 七、台词重复（「鬼打墙」）

成片听起来像卡带，通常是这两个原因，系统会直接报出来：

**① 同一镜里同一句出现两遍**

```
错：1s 【王蝉】冷冷地说道：“你走吧。”
    3s 【王蝉】重复了一遍：“你走吧！”
```

要么删掉一次，要么把那句改成真正的新台词。剧情确实要复述时，必须写成不同的表述。

**② 把上一镜的台词又写了一遍**

上一镜的内容只能用来判断"从哪里接"，**一个字都不许重复**。系统会给 warning（不阻断，但成片会显得两镜在打转）。

判定口径：比较时去掉标点空白，所以 `你走吧。` 和 `你走吧！` 算同一句；少于 3 个字的短应答（`嗯` `好`）不判。
