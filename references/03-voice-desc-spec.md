# 音色描述规范

> 音色 = 让"这个人的台词"听起来是这个人在说。
> 系统按描述生成一段音频，**同一段描述会稳定生成同一个音色**（想换音色就改描述）。

## 一、`voiceDescription` 怎么写

按五要素写，**一段话，30~80 字**：

1. **性别 + 年龄段**（青年男性 / 中年女性 / 老年男性）
2. **音色质感**（低沉浑厚 / 清亮干净 / 沙哑粗粝 / 尖细 / 温和）
3. **语速与节奏**（语速偏慢、字字顿挫 / 语速快、尾音上扬）
4. **情绪基调**（冷静克制 / 阴冷威胁 / 温和关怀 / 急促慌乱）
5. **口音或说话习惯**（可选：带北方口音 / 尾音拖长 / 句末轻叹）

例子：

```
中年男性，嗓音低沉浑厚略带沙哑，语速偏慢字字顿挫，语气阴冷带着压迫感，句尾习惯微微下压
```

```
青年女性，音色清亮干净，语速适中，语调温和克制，情绪低落时尾音会轻微发颤
```

## 二、`text` 怎么写

- 用**这个角色在第一章里真实会说的那句台词**（从分镜提示词里挑一句）。
- 一句就够，不要太长（系统有字数上限）。
- 台词里的语气词、停顿标点照原样保留，这些会影响生成效果。
- 不要用旁白句去配角色音色（旁白应该是另一个音色）。

## 三、`saveVoiceToLibrary` 的命名

- `name` 用「角色名-特征」，例如 `洪宇-低沉男声`、`苏晚-清亮女声`。
- 同名会自动编号，不会覆盖旧音色，所以可以放心多试几版（`洪宇-低沉男声1`、`2`）。
- `ageType` 填 少年 / 青年 / 中年 / 老年；`six` 填 男 / 女。**必须和人物表的 ageType / six 一致**，否则页面按年龄性别筛选时会找不到。

## 四、流程与坑

1. `designVoice(voiceDescription, text, bookId)` → 返回 `taskId`。
2. 每 20 秒 `getVoiceResult(taskId)`，直到 `done=true`（一般 30~90 秒）。
3. `status=success` → `saveVoiceToLibrary(path, name, ageType, six)`。
4. `status=failed` → 读 `message`，换一版描述重试一次。
5. 返回"任务不存在" → 服务重启过（记录只在内存），重新 `designVoice`。

**特别注意**：

- 入库只完成"音色进了音色库"这一步。**把音色绑到人物上仍需人工在网页操作一次**，你要在回复里明确提醒用户。
- 音色文件是磁盘上的绝对路径。如果用户清理过 ComfyUI 的 input 目录，全库音色会集体失效，出片会报「音色文件不存在」。遇到这个报错，让用户重新入库音色，不要反复重跑视频。
- 一个人只有一个音色。同一角色在不同镜里必须用同一个音色，否则听起来像换人。
